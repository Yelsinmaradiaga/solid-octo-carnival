# solid-octo-carnival

Sitio estático para **The WallSpire Podcast** listo para iniciar publicación de contenido.
La versión actual carga **sin depender de Google Fonts/Unsplash** (modo offline-friendly).

## Archivos

- `index.html`: landing principal con episodios, invitados, blog y asistente de búsqueda.
- `content-template.json`: plantilla para comenzar a cargar contenido real (episodios, invitados y blog).

## Cómo empezar

1. Abre `index.html` para vista local.
2. Rellena `content-template.json` con tu contenido.
3. Conecta ese JSON a Firebase/CMS o reemplaza el objeto `CONTENT` dentro de `index.html`.
